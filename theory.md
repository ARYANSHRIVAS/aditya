control structure :- control structure shows execution flow of program.

types of control structure :-
1. conditional control structure:-
a. if statement
 syntax:- 
 if(conditions):
    statement or logic 

 b. if else statement

 c. multiple if statement
 syntax:- 
 if(condition1):
    statement1
if(condition2):
    statement2
if(conditon3):
    statement3
